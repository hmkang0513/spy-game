## 2. UI 패턴 정리

### 시야 원뿔
- 지형에 가려지는 원뿔 + **빗금(웅크리면 안전) 구역**을 구분한다 [3][4][5]. 2D에서는 "서 있을 때 시야 거리"와 "웅크렸을 때 시야 거리"를 다르게 잡아 원뿔을 두 겹으로 그리면 된다(추론, Godot 셰이더 예시의 높이 2회 판정을 2D로 단순화) [3].
- 기본은 화면 안 모든 경비의 원뿔을 표시한다. Desperados처럼 클릭으로 원뿔을 강조하고 지점 감시 마커를 두는 기능은 L3 이후 선택 기능으로 둔다 [5].
- Monaco처럼 화면 전체의 색이 바뀌면 경비 시야가 헷갈린다는 비판이 있다. 원뿔은 단색 반투명 + 외곽선으로 그린다 [8].

### 감지 미터 / 경계 상태
- 감지는 **즉시가 아니라 게이지가 차는 방식**으로 한다. 즉시 발각은 시행착오식 설계로 이어진다는 지적이 있다 [24]. 포럼에서도 "빨간색이 되기 전까지는 경고"로 읽히는 중간 상태가 공정하다는 의견이 있다 [25].
- 경비 머리 위 아이콘: 노란 ?(의심·조사), 빨간 !(발각). 상태가 바뀐 원인(소리, 마지막 목격 위치 고스트)을 보여 준다 [1][2].
- 레벨 전역 상태는 MGS식 **평시 → 의심 → 경보 → 수색 → 주의**로 나누고, 화면 상단 띠의 색으로 표시한다 [13][14].

### 은신 표시
- 숨은 상태에서는 캐릭터를 실루엣이나 어두운 톤으로 바꾼다 [1]. 덧붙여 Thief식 "노출도" 아이콘을 화면 하단에 둔다 [11].
- 은신처(화분·커튼·상자) 근처에 상호작용 키 힌트를 띄운다. 숨은 동안에는 화면 비네팅으로 상태를 확실히 알린다(추론).

### 단서 수첩
- Ace Attorney 방식: 탭(인물/문서/물건) + 카드 목록. 대화 중에 **"제시"** 버튼으로 수첩을 연다 [16].
- Obra Dinn 방식 진행도: 인물 카드에 "알아낸 정보 n/3"을 표시하고, 핵심 단서를 얻으면 카드가 선명해진다 [20].
- 새 단서를 얻으면 토스트 알림과 수첩 아이콘 배지를 띄운다(추론).

### 잠긴 대화 선택지
- **숨기지 말고 회색으로 표시하되 필요 조건을 쓴다.** 예: `[단서 필요: 대사관 초대장]`. 회색 처리만 하면 "미구현인지 조건 미충족인지" 헷갈린다는 피드백이 있다 [26][27].
- 스포일러가 되는 선택지만 숨긴다 [26]. Disco Elysium처럼 체크의 종류와 조건을 미리 보여 주면 선택이 신중해진다 [17][18].

### 목표 마커
- 맵 가장자리에 화살표 + 거리를 표시한다. 조사 단계에서는 "누구와 대화해야 하는지"만 표시하고 잠입 단계에서는 목표 방향을 표시한다(추론, 직접 출처 없음).

## 3. 흔한 불만과 회피책

| 불만 | 근거 | 회피책 |
|---|---|---|
| 즉시 발각 → 시행착오 반복 | [24][25] | 감지 게이지에 0.6~1.0초 유예. 거리가 멀수록 천천히 차게(추론) |
| "내가 보이는지 모르겠다" | [11][25] | 숨음 실루엣 + 노출도 아이콘 + 빗금 원뿔 [1][3][11] |
| 경비 행동이 예측 불가 | [1][10] | 순찰 경로를 고정하고 타입별로 외형을 다르게. 상태 변화 원인을 표시 |
| 실패 후 긴 재시작 | [1] | 조우마다 체크포인트, 1초 이내 재시작 [1] |
| 세이브 스컴 | [12][19] | 수동 세이브 대신 자동 체크포인트. 발각돼도 경보 → 수색 → 복귀로 이어 가기 [13]. 실패를 다른 루트로 연결 [18] |
| 지루한 자물쇠 따기 | [12] | 5초 안팎의 타이밍 미니게임. 실패하면 소음만 발생(추론) |
| 넓은 맵에서 길을 잃음 | [1] | 조우 공간은 "한 화면 + 0.5~0.75 화면" 정도 [1] |
| 능력·상호작용 과다 | [9] | 능력 상한 5~6개 유지, 레벨당 1~2개 도입 [10] |

## 4. 3개 레벨 구체 권장안

### 공통 감지 규칙(초안, 추론 기반으로 수치는 플레이테스트로 조정)
- 원뿔 안 & 시야 차단 없음 → 감지 게이지 상승(근거리 빠름, 원거리 느림). 게이지 50%에서 ?(조사), 100%에서 !(발각).
- 빗금 구역에서 웅크린 상태면 감지 0. 은신처 안에서는 항상 감지 0 [3][4].
- 발각되면 레벨 경보가 1단계 오른다(Invisible Inc식 누적) [7]. 경보 3단계 또는 경비 접촉 시 체크포인트로 복귀한다.
- 결과 화면: 발각 횟수, 수집 단서 수, 소요 시간 → 등급. 재도전 동기는 주되 처벌은 하지 않는다(추론).

### L1 항구 카페 접선 (이동·대화·단서 수첩)
- **경비 없음**, 실패 조건 없음. 조사 → 대화 루프만 가르친다(Hitman GO식 한 번에 개념 1개) [10].
- 단서 3~4개, NPC 3명. 마지막 접선 대화에서 **잠긴 선택지 1개**를 보여 주고, 단서를 얻은 뒤 열리게 해서 "단서 = 열쇠" 규칙을 체득시킨다 [16][26].
- 잠긴 선택지에 `[단서 필요: ○○]`를 표시하고, 수첩 "제시" UX를 1회 강제한다.
- 길이 5~8분(추론). 끝부분에 순찰 NPC 1명을 원뿔만 보여 주며 예고한다(감지 없음).

### L2 대사관 파티 (숨기/웅크리기, 경비 시야·순찰, 변장 대화)
- 순서: ① 정지 경비 1명 + 빗금 원뿔에서 웅크리기 → ② 순찰 경비 + 은신처(커튼·화분) → ③ 변장 대화.
- 첫 구간은 실패해도 바로 직전으로 돌아가는 체크포인트. 구간마다 체크포인트를 둔다 [1].
- 변장 대화: 경비에게 들켰을 때 "초대장" 단서가 있으면 `[제시: 초대장]`으로 상황을 무마한다 → 단서가 잠입의 안전망이 된다(추론, Ace Attorney 제시 + Sneaky Sasquatch 변장 결합) [15][16].
- 경보 단계는 L2에서 처음 표시한다(?/! 아이콘 포함) [2][13].

### L3 지하 연구소 (자물쇠 따기, 동전 던져 유인)
- 자물쇠: 짧은 타이밍 미니게임(3핀 이하). 실패하면 소음 원이 생겨 경비가 ?로 반응 → 능력끼리 연결 [2][12].
- 동전 던지기: 조준 중에 **소음 반경 원 + 반응할 경비 하이라이트**를 미리 보여 준다(Mark of the Ninja) [2]. 첫 사용처는 "경비 1명이 문 앞에 정지, 옆에 빈 방" 같은 단일 해법 퍼즐로 둔다.
- 이후 구간에서 "동전 유인 → 자물쇠 → 통과"를 조합하게 한다. 탈출 구간은 경보 상태에서 시작해 MGS식 수색 → 복귀를 체험시킨다 [13][14].
- 탈출 직전에 체크포인트를 둔다. 탈출 실패 시 목표 획득부터 다시 하지 않게 한다 [1].

### 체크포인트 원칙
- "새 개념 소개 직전 + 조우 공간 입구 + 목표 획득 직후"에 자동 저장한다. 재시작은 1초 이내 [1].
- 단서 수첩·획득 아이템은 체크포인트에서 유지한다(조사를 반복하지 않게, 추론).

## 2. 툴체인 버전 (TypeScript 7 호환성)

### TypeScript 7.x 판단
- `typescript@7.0.2`(2026-07-08)는 Go 네이티브 컴파일러. 패키지 exports가 `./unstable/*` API만 노출하고 기존 `lib/typescript.js` 프로그래매틱 API가 없음.
- **typescript-eslint 최신 8.71.2도 peer `typescript: ">=4.8.4 <6.1.0"`** → TS 7 설치 시 peer 충돌. TS 7 지원 이슈(#12518)는 "not planned"로 닫힘, 안정 API는 TS 7.1 예정(현재 `7.1.0-dev`만 존재, 미출시).
- Vite/Vitest는 esbuild/oxc로 트랜스파일만 하므로 TS 버전 무관. 타입체크(`tsc --noEmit`)만 TS 버전 영향.
- **결론: `typescript@6.0.3` 고정** (typescript-eslint 지원 범위 내 최신 안정). 원하면 `tsc` 속도용으로 TS7을 npm alias(`"tsgo": "npm:typescript@7.0.2"`)로 병행 가능하나 MVP에선 불필요.
