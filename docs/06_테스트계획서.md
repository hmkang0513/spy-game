## 1. 목적·범위
- 01_요구사항정의서의 인수 기준(AC-01~62)과 비기능 요구(NFR)를 검증한다.
- 테스트는 **구현 코드가 아니라 요구사항과 계약에서** 작성한다(구현에 끌려가는 테스트 방지).

| 대상 | 범위 |
|---|---|
| 포함 | core 로직, 레벨 데이터 무결성, 저장, 씬 흐름, 레벨 1~3 클리어 경로 |
| 제외 | 아트 품질, 난이도 체감(플레이테스트로 별도 조정), Safari |

## 3. 진입·완료 기준
- **진입**: 토대 구축 완료(`npm run dev` 기동, 계약 타입 컴파일 성공).
- **완료**:
  - `npm run lint`, `npm run typecheck`, `npm test`, `npm run test:e2e` 모두 통과
  - Must 기능 관련 AC 전부 ✅ (추적표 §5)
  - 수동 체크리스트 §6의 레벨 1~3 클리어 확인
  - 실패 시 수정 루프 최대 3회, 이후 잔여 이슈로 보고
