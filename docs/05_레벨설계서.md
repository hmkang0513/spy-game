### 세계관 (공통)
- 주인공: **윤하늘**, 코드네임 **모스(Moth)**. 비밀 정보기관 '등대'의 신입 요원. 짧은 단발, 남색 트렌치코트, 빨간 스카프.
- 국장: **체리 국장**(브리핑 화면 전용). 은발 올림머리, 보라 정장, 늘 사탕을 문다.
- 적: 밀수 조직 **까마귀 상회**. 천재 발명가 주노아 박사의 초소형 배터리 "오로라 칩"을 손에 넣으려 한다.
- 톤: 가볍고 세련된 첩보물. 위트 있는 대사가 많고 폭력 묘사는 없다.

### L1 「항구 카페 접선」 — 예상 5~8분, 목표 시간 6분
**줄거리**: 신입 모스의 첫 임무. 항구 카페 '블루 앵커'에서 정보원 페퍼를 만나 까마귀 상회의 다음 거래 정보를 받아야 한다. 그런데 페퍼는 정해진 암호 주문을 하는 사람만 상대한다.

**맵 (28×20 타일)**
- 남쪽 입구(시작) → 1층 홀(테이블 6개, 12×8) → 동쪽 카운터·주방 입구(6×8) → 북쪽 창가석(페퍼 자리, 10×4) → 서쪽 테라스(바다 쪽, 8×10, 영수증 오브젝트) → 입구 밖 부두 길(28×3, 엔딩 때 경찰 순찰 예고).

**NPC**
| 이름 | 역할 | 외형 |
|---|---|---|
| 페퍼 | 정보원 | 중년 남성, 회색 페도라, 베이지 트렌치코트, 파란 우산, 신문 |
| 미오 | 바리스타·카페 주인 | 20대 여성, 분홍 투블록 머리, 갈색 앞치마, 팔 토시 |
| 도 갑판장 | 단골 노선원 | 흰 수염, 노란 비옷, 선원 모자, 파이프 |
| 루 | 여행 중인 화가 | 긴 곱슬머리, 파란 스카프, 물감 묻은 멜빵바지 |
| 순찰 경찰 | 엔딩 예고용 | 남색 제복, 경찰모(L2 경비와 같은 계열) |

**단서**
| ID | 이름 | 획득 | 사용처 |
|---|---|---|---|
| C1-01 | 등대 요원 배지 | 시작 소지 | 페퍼의 "누가 보냈지?"에 제시(강제 제시 튜토리얼) |
| C1-02 | 접선자 인상착의 | 브리핑 | 정보 메모: "파란 우산, 신문". 루에게 잘못 말을 걸면 웃긴 오답 대사 |
| C1-03 | 단골 주문 쪽지 | 미오 대화(주문하기 선택 후) | 페퍼 잠긴 선택지 `[단서 필요: 단골 주문 쪽지]` = 암호 주문 |
| C1-04 | 젖은 영수증 | 테라스 바닥 조사 | (선택) 페퍼에게 제시 → 상회 선박명 추가 정보(C1-05) |
| C1-05 | 상회 화물선 '흑깃호' **(이월)** | 페퍼(C1-04 제시) | 선택 단서, 등급용. L2에서 까마귀 부인 대화의 추가 선택지 |
| C1-06 | 대사관 파티 초대장 **(이월)** | 페퍼(암호 성공) | L2 입장, 검문 무마 |

**대화 개요**
- 미오: 인사 → "주문하시겠어요?" → [아무거나 추천] / [창가 손님이 마시는 걸로] → 후자 선택 시 "그분은 매일 '소금 라테, 얼음 셋'이에요" + C1-03.
- 도 갑판장: 항구 잡담 → "요즘 밤마다 검은 깃발 단 배가 들어와" (힌트). 테라스 영수증 위치를 넌지시 알려 준다.
- 루: 파란 스카프 때문에 접선자로 착각하기 쉽다. [암호를 말한다] → "…라테 그림 그려 드려요?" (오답 유머, 처벌 없음).
- 페퍼: "누가 보냈지?" → **제시 요청**(C1-01) → [그냥 커피 마시러] / [소금 라테, 얼음 셋 `[단서 필요: 단골 주문 쪽지]`] → 성공 시 C1-06 지급 → (C1-04 있을 때) [이 영수증 아세요?] → C1-05.

**목표**: ① 접선자 찾기 ② 암호 알아내기 ③ 페퍼에게 정보 받기 ④ 카페 나가기
**경비/체크포인트**: 경비 없음. 체크포인트 불필요(실패 없음). 출구에서 경찰 1명이 원뿔을 켠 채 지나가는 연출.

### L2 「대사관 파티」 — 예상 12~15분, 목표 시간 12분
**줄거리**: 가상 국가 벨모라 공화국 대사관의 가면 없는 가든 파티. 까마귀 상회 간부가 이곳에서 주노아 박사의 칩 거래를 확정한다는 정보다. 모스는 손님으로 들어가, 직원 구역의 대사 집무실에서 거래 문서를 빼내야 한다.

**맵 (40×30 타일)**
- 남쪽 정문 로비(10×6, 접수대) — 손님 허용
- 중앙 연회장(18×12, NPC 다수, 경비 없음) — 손님 허용
- 서쪽 정원·테라스(12×10, 정지 경비 G1, 빗금 구역 연습용 울타리·대형 화분) — 손님 허용
- 동쪽 화장실 복도(4×10) — 손님 허용 / 끝에 "직원 전용" 문
- 북동 직원 복도(16×4, 순찰 G2, 커튼 은신처 3곳) — 직원 전용
- 경비 대기실(6×5, 순찰표 오브젝트) — 직원 전용
- 북쪽 대사 집무실(8×6, 서랍, 앞에 회전 경비 G3) — 직원 전용
- 북서 주방(10×6, 사물함 은신처 2곳) → 뒷문(출구)

**NPC**
| 이름 | 역할 | 외형 |
|---|---|---|
| 벨라 | 접수원 | 금발 포니테일, 진녹색 드레스, 클립보드 |
| 오스왈드 크레인 | 벨모라 대사 | 흰 콧수염, 대머리, 훈장 달린 연미복 |
| 나리 | 주노아 박사의 비서 | 동그란 안경, 검은 단발, 회색 정장, 태블릿 |
| 토비 | 웨이터 | 10대 후반, 곱슬 갈색머리, 흰 셔츠·나비넥타이, 쟁반 |
| 까마귀 부인 | 상회 간부 | 검은 깃털 모자, 검은 롱드레스, 붉은 립스틱, 부채 |
| G1 / G2 / G3 | 경비 | §4.5 AC-31 타입별 외형 + 얼굴·머리색은 각자 다르게 |

**단서**
| ID | 이름 | 획득 | 사용처 |
|---|---|---|---|
| C2-01 | 경비 순찰표 | 경비 대기실 책상 조사 | G2 순찰 경로 점선 표시(S4). 토비 대화 추가 선택지 |
| C2-02 | 비서의 걱정 | 나리 대화 | "박사님이 연구실을 어딘가 지하로 옮겼대요" — 나리 후속 대화 조건 |
| C2-03 | 상회 거래 문서 **(이월)** | 집무실 서랍 | **필수**. 나리에게 제시 → C2-04. L3 장소 확인 |
| C2-04 | 박사의 메모 **(이월)** | 나리(C2-03 제시) | **필수**. "금고 번호는 늘 '첫 실험 날'로 해 둔다." → L3 조합 |
| C2-05 | 까마귀 부인의 명함 **(이월)** | 까마귀 부인 대화(C1-05 선택지 또는 칭찬 선택지) | 선택. L3 연구원 모모에게 제시해 출입증 획득 |
| C2-06 | 토비의 귀띔 | 토비 대화 | "9시 종이 울리면 복도 경비가 주방에 간식 먹으러 가요" — G2 순찰에 주방 경유 구간이 있음을 알림 |

**대화 개요**
- 벨라(입장): "초대장 확인하겠습니다." → [이름을 댄다] (거절 유머) / [초대장을 보여 준다 `[단서 필요: 대사관 파티 초대장]`] → 입장. (L1을 클리어했으면 항상 갖고 있다)
- 대사: 파티 인사, 정원 자랑. [집무실이 어디죠?] → "직원 구역 안쪽이라오, 허허" (위치 힌트).
- 나리: 걱정 토로 → C2-02 → 이후 [이 문서를 보세요 `[단서 필요: 상회 거래 문서]`] → 상회가 박사를 노린다는 걸 알고 협조 → C2-04.
- 토비: 쟁반 대화 → C2-06 → [순찰표 얘기 `[단서 필요: 경비 순찰표]`] → "주방 사물함 두 번째는 고장 나서 안 잠겨요" (은신 힌트).
- 까마귀 부인: 의심하는 말투 → [드레스 칭찬] / [흑깃호 잘 들어왔나요? `[단서 필요: 상회 화물선 '흑깃호']`] → 같은 편으로 오인해 명함 C2-05를 바로 준다. 칭찬 선택지만 고른 경우에는 **두 번째 대화에서** 명함을 준다(무작위 없음, L1 선택 단서를 놓쳐도 얻을 수 있다).
- 경비 검문(AC-40): "여긴 손님 구역이 아닌데요?" → **제시 요청**: 초대장 → "화장실을 찾다가…" → 연회장 입구로 이동.

**목표**: ① 파티 입장 ② 집무실 위치 알아내기 ③ 직원 구역 잠입 ④ 거래 문서 확보 ⑤ 나리에게 박사 정보 얻기 ⑥ 뒷문 탈출
**경비 순찰**
- G1(정지·좌우 회전): 정원 중앙, 4초마다 왼쪽↔오른쪽 90° 회전. 울타리 뒤 빗금 구역에서 웅크리기를 처음 가르치는 곳.
- G2(순찰): 직원 복도 서→동 → 경비 대기실 → 주방 입구 → 복도 복귀, 1바퀴 약 40초. 커튼 3곳에서 피할 수 있다.
- G3(회전): 집무실 문 앞, 180° 구간을 6초 주기로 훑는다. 원뿔이 문 반대쪽을 볼 때 약 2초간 빈틈이 생긴다.
**체크포인트**: CP2-1 정원 입구(첫 잠입 개념 직전), CP2-2 직원 전용 문 안쪽, CP2-3 문서 획득 직후(집무실 앞).

### L3 「지하 연구소」 — 예상 15~20분, 목표 시간 15분
**줄거리**: 거래 문서가 가리킨 곳은 소금곶 통조림 공장 지하. 상회가 납치하듯 옮겨 놓은 주노아 박사의 연구소다. 박사는 이미 몸을 피했고, 금고 속 오로라 칩만 남았다. 모스는 자물쇠와 동전 하나로 연구소를 통과해 칩을 빼내야 한다.

**맵 (40×30 타일)**
- 남쪽 하역장(12×8, 시작·CP3-1, 청소부 말순 여사, 상자 은신처)
- 중앙 창고 복도(T자, 폭 3, 길이 24, 순찰 G4)
- 서쪽 휴게실(8×6, 연구원 모모, 자판기)
- 서북 연구실 A(8×8, 잠긴 문 3핀, 실험일지)
- 동쪽 경비실(8×6, 정지 경비 G5, 문 앞 정지 → 첫 동전 퍼즐: 옆 빈 창고에 동전 던져 유인)
- 북쪽 금고실 대기 복도(12×4, 회전 경비 G6) → 금고실(8×6, 카드 문 또는 4핀 자물쇠)
- 북동 화물 엘리베이터(탈출구) / 북서 비상 통로(잠긴 3핀 문, C3-04 있으면 표시됨, 지름길)

**NPC**
| 이름 | 역할 | 외형 |
|---|---|---|
| 말순 여사 | 청소부, 동전 지급 | 70대, 꽃무늬 두건, 연두색 작업복, 대걸레 |
| 모모 | 겁 많은 연구원 | 주황 곱슬머리, 흰 가운, 두꺼운 고글을 이마에 |
| 브루노 | 경비대장(G6) | 거구, 빨간 베레모, 검은 전술 조끼, 콧수염 |
| G4 / G5 | 경비 | 회색 작업 제복, 헬멧(G4) / 야구모자(G5) — 얼굴·피부색 각자 다르게 |

**단서**
| ID | 이름 | 획득 | 사용처 |
|---|---|---|---|
| C3-01 | 실험일지 | 연구실 A 책상(자물쇠 따기 후) | "작성 시작 2월 2일 / 첫 실험 3월 21일 성공!" — C2-04와 연결 |
| C3-02 | 금고 번호 0321 | **연결**: C2-04 + C3-01 | 금고 대화 선택지 `[단서 필요: 금고 번호]` |
| C3-03 | 연구원 출입증 | 모모(C2-05 제시) | 금고실 카드 문을 바로 연다(4핀 자물쇠 우회) |
| C3-04 | 비상 통로 소문 | 말순 여사 대화 | 비상 통로 문을 맵에 표시, 탈출 지름길 |
| C3-05 | 경비실 근무표 | 경비실 벽(G5 유인 후) | 선택 단서. G6 브루노가 8초마다 하품하며 2초 눈을 감는다는 메모 → 해당 빈틈이 원뿔 깜빡임으로 보인다 |
| C3-06 | 오로라 칩 | 금고 | 최종 목표 아이템 |

- 오답 조합 예: C2-04 + C3-01에서 2월 2일을 고르면 안 되도록, 연결 결과는 "첫 실험 날 = 3월 21일 → 0321" 하나로 고정. 금고에서 직접 숫자를 입력할 수도 있으며, 3회 틀리면 경보.

**대화 개요**
- 말순 여사: "젊은이, 여기 사람 아니지?" → [청소 도와드릴게요] → 동전 3개 지급(동전 던지기 해금 튜토리얼) → [다른 출구는 없나요?] → C3-04.
