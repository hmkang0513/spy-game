## 1. 목표 / 대상 사용자 / 비목표

### 1.1 목표
1. **"단서 = 열쇠"**: 조사로 모은 단서가 대화 선택지와 잠입 경로를 실제로 연다. 레벨 3개 모두에서 이 규칙이 핵심 재미가 된다.
2. **공정한 잠입**: 플레이어가 "내가 보이는지" 항상 알 수 있다(시야 원뿔, 감지 게이지, 은신 표시, 경보 띠).
3. **점진적 능력 해금**: 레벨마다 새 개념을 1~2개만 들여오고, 능력은 6개에서 더 늘리지 않는다.
4. 레벨 1~3을 처음부터 끝까지 30~45분 안에 클리어할 수 있고, 결과 등급으로 재도전할 동기를 준다.

### 1.2 대상 사용자
- 짧은 시간에 끝나는 스토리형 인디 게임을 좋아하는 PC 웹 사용자(한국어)
- 잠입 장르 초보~중급자. 잠입 장르를 처음 하는 사람도 L1~L2만으로 규칙을 익힐 수 있어야 한다.

### 1.3 비목표
- 전투·살상(제압, 무기). 이 게임에서는 발각되면 회피하거나 말로 넘긴다.
- 레벨 4 이상, 절차적 맵 생성, 멀티플레이, 서버 저장
- 모바일·게임패드 대응(입력 계층만 분리해 두고 구현은 하지 않는다)

## 3. 사용자 스토리
- US-01 플레이어로서 브리핑에서 임무 목표와 첫 단서를 받아, 무엇부터 조사할지 알고 싶다.
- US-02 플레이어로서 NPC와 대화해 단서를 모으고, 모은 단서를 수첩에서 언제든 다시 읽고 싶다.
- US-03 플레이어로서 잠긴 선택지에 필요한 단서가 무엇인지 보고, 그 단서를 찾으러 가고 싶다.
- US-04 플레이어로서 대화 중에 수첩에서 단서를 골라 "제시"해 상대의 반응을 바꾸고 싶다.
- US-05 플레이어로서 경비의 시야와 감지 정도를 화면에서 읽고, 걸리기 전에 피할 기회를 갖고 싶다.
- US-06 플레이어로서 웅크리거나 은신처에 숨어 경비를 따돌리고 싶다.
- US-07 플레이어로서 들켰을 때 초대장을 내밀어 말로 넘기고 싶다(L2).
- US-08 플레이어로서 자물쇠를 짧은 타이밍 게임으로 따고, 실패하면 소음이라는 대가를 치르고 싶다.
- US-09 플레이어로서 동전을 던져 경비를 유인하고, 던지기 전에 어느 경비가 반응할지 미리 보고 싶다.
- US-10 플레이어로서 두 레벨에서 얻은 단서를 조합해 금고 번호를 추리하고 싶다.
- US-11 플레이어로서 실패해도 가까운 체크포인트에서 바로 다시 하고 싶다.
- US-12 플레이어로서 브라우저를 닫았다 열어도 진행 상황과 최고 등급이 남아 있기를 원한다.

## 4. 인수 기준 (Acceptance Criteria)

### 4.1 코어 / 씬 흐름
- AC-01 첫 실행 시 `document.fonts.load('11px Galmuri11')`이 끝난 뒤 타이틀 씬이 뜨고, 모든 한글 텍스트가 Galmuri로 렌더링된다.
- AC-02 타이틀 → 레벨 선택 → 브리핑 → 레벨 → 결과 → 레벨 선택 순서로 이동한다. 각 전환은 0.5초 이하 페이드다 **(조정값)**.
- AC-03 레벨 선택에서 잠긴 레벨은 자물쇠 아이콘과 "이전 레벨 클리어 필요"를 보여 주고, 선택되지 않는다.
- AC-04 브리핑에는 임무 목표 목록, 이번 레벨에서 새로 얻는 능력, 시작 단서가 표시되며 "임무 시작"을 누르면 레벨이 시작된다.
- AC-05 기준 해상도는 640×360(32px 타일 기준 20×11.25 타일)이고 `pixelArt: true`, `roundPixels: true`다. 창 크기에 맞춰 ×1/×2/×3 정수 배율로 확대하고 남는 영역은 레터박스로 채운다.
- AC-06 Esc로 일시정지 메뉴(계속 / 체크포인트에서 재시작 / 레벨 선택으로)가 열리고, 일시정지 중에는 경비·타이머·게이지가 멈춘다.
- AC-07 화면 우상단에 현재 목표 1줄이 표시되고, 목표를 달성하면 다음 목표로 바뀌며 토스트 알림이 뜬다.

### 4.2 이동
- AC-08 WASD와 방향키로 이동하며, 대각선 이동 속도는 정규화된다(직선 속도와 같다).
- AC-09 걷기 속도 120px/s, 웅크리기 속도 60px/s **(조정값)**.
- AC-10 이동 방향에 맞는 4방향 걷기 애니메이션이 재생되고, 멈추면 마지막 방향의 정지 프레임으로 돌아간다.
- AC-11 벽·가구 타일은 통과할 수 없고, 충돌 박스는 발밑 20×12px이다 **(조정값)**.

### 4.3 대화
- AC-12 상호작용 범위(1.5타일 **(조정값)**) 안의 NPC나 오브젝트 위에 `E` 힌트가 뜨고, E를 누르면 대화가 시작된다.
- AC-13 대화 중에는 플레이어 이동이 막히지만 경비는 계속 움직인다. 대화 중에는 감지 게이지가 오르지 않고 경보 상태도 멈춘다(경보가 대화로 식지 않는다). 대화 중 걸린 경보는 대화가 끝난 직후 적용한다. L1은 경비 감지가 없다.
- AC-14 선택지는 마우스 클릭 또는 숫자키 1~4로 고른다.
- AC-15 단서 조건을 채우지 못한 선택지는 숨기지 않고 회색으로 표시하며, 끝에 `[단서 필요: <단서명>]`을 붙인다. 클릭해도 반응하지 않는다.
- AC-16 조건 단서를 얻으면 같은 선택지가 일반 색 + 단서 아이콘으로 바뀌어 선택할 수 있다.
- AC-17 "제시" 요청 노드에서는 수첩이 제시 모드로 열린다. 맞는 단서를 내면 성공 분기로, 틀린 단서를 내면 NPC의 오답 반응 후 다시 고를 수 있다(처벌 없음).
- AC-18 대화 데이터는 JSON이며, 모든 노드가 도달 가능하고 끊긴 `next`가 없는지 Vitest로 검증한다.
- AC-19 한 번 본 대화 노드는 재방문 시 요약 대사로 짧아진다.

### 4.4 단서
- AC-20 단서를 얻으면 "단서 획득: <이름>" 토스트가 뜨고 수첩 아이콘에 배지가 붙는다. 배지는 수첩을 열면 사라진다.
- AC-21 Tab으로 수첩을 열고 닫는다. 탭은 인물 / 문서 / 물건이고, 카드마다 이름·설명·출처(누구에게서, 어디서)를 보여 준다.
- AC-22 같은 단서는 두 번 얻지 않는다(중복 토스트 없음).
- AC-23 (L3) 수첩에서 단서 2개를 골라 "연결"하면, 유효한 조합일 때 새 단서가 생기고, 유효하지 않으면 "연결되지 않는다" 메시지만 뜬다(처벌 없음).
- AC-24 레벨 간 이월 단서([05_레벨설계서](05_레벨설계서.md) 단서 표의 "이월" 표시)는 레벨을 클리어할 때 저장되고, 다음 레벨 시작 시 수첩에 들어 있다.

### 4.5 잠입 / 시야
- AC-25 경비 시야 원뿔은 각도 70°, 거리 7타일이며 **(조정값)**, 벽 타일에 가려지는 폴리곤으로 그린다(레이 수 ≥ 24).
- AC-26 원뿔은 3구역이다 **(조정값)**: ① 근거리 0~2.5타일(진한 색), ② 중거리 2.5~5타일(보통 색), ③ 빗금 구역 5~7타일(빗금). 단색 반투명 + 외곽선으로 그리고, 화면 전체 색은 바꾸지 않는다.
- AC-27 감지 게이지 충전 시간 **(조정값)**: ①구역 0.4초(웅크려도 동일), ②구역 서기 1.0초 / 웅크리기 2.0초, ③구역 서기 1.6초 / 웅크리기 감지 없음.
- AC-28 원뿔 밖에서는 게이지가 초당 40%씩 줄어든다 **(조정값)**.
- AC-29 게이지가 50% 이상이면 경비 머리 위에 노란 `?`가 뜨고 경비가 플레이어 쪽으로 몸을 돌려 그 위치로 다가간다(조사). 100%가 되면 빨간 `!`와 함께 "발각" 처리된다.
- AC-30 게이지가 0을 넘는 순간 원뿔 외곽선이 깜빡여 감지가 시작됐음을 알린다(유예 시간 동안 피할 수 있다).
- AC-31 경비 타입별로 외형이 다르다: 정지(제복 + 모자), 회전(제복 + 선글라스), 순찰(정장 + 이어피스). 순찰 경로는 고정 웨이포인트다.

### 4.6 경보 상태 머신
- AC-32 레벨 전역 상태는 평시 / 의심 / 경보 / 수색 / 주의 5단계이며 화면 상단 띠 색(없음 / 노랑 / 빨강 / 주황 / 연노랑)과 글자로 표시된다.
- AC-33 전이 규칙 **(조정값)**:
  - 평시 → 의심: 경비 1명이라도 게이지 50% 이상, 또는 소음에 반응
  - 의심 → 평시: 모든 경비 게이지 0 + 조사 종료(4초)
  - 아무 상태 → 경보: 발각(게이지 100%). 경보 진입 횟수를 1 올린다.
  - 경보 → 수색: 모든 경비가 플레이어를 3초 동안 못 봄
  - 수색 → 경보: 수색 중 재발각
  - 수색 → 주의: 수색 20초 경과
  - 주의 → 평시: 30초 경과
- AC-34 경보 중에는 모든 경비가 마지막 목격 위치로 A* 이동하고 이동 속도가 1.5배가 된다. 수색 중에는 목격 위치 주변 반경 5타일의 무작위 지점 3곳을 돈 뒤 원래 순찰로 돌아간다.
- AC-35 주의 상태에서는 원뿔 거리가 +1타일 늘어난다 **(조정값)**.
- AC-36 경보 중 경비와 접촉(0.75타일 이내)하면 "붙잡힘" 화면 후 마지막 체크포인트에서 재시작한다. L2의 변장 대화가 가능한 경우는 예외다(AC-40).

### 4.7 숨기 / 웅크리기 / 변장
- AC-37 C(토글) 또는 Shift(누르는 동안)로 웅크린다. (Ctrl은 Ctrl+W 등 브라우저 단축키와 겹쳐 쓰지 않는다) 웅크린 상태에서는 스프라이트가 낮아지고 이동 속도가 줄어든다.
- AC-38 은신처(커튼·대형 화분·사물함·상자) 1타일 안에서 E를 누르면 숨는다. 숨은 동안 캐릭터는 어두운 실루엣이 되고 화면 가장자리에 비네팅이 생기며, 감지 게이지는 항상 0이다.
- AC-39 숨기 진입·탈출에는 0.3초가 걸린다 **(조정값)**. 경비가 숨는 장면을 ①구역에서 직접 보면 숨기에 실패하고 발각된다.
- AC-40 (L2) 연회장과 이어진 "손님 허용 구역"(로비·연회장·정원·화장실 복도)에서 발각되면 경보 대신 검문 대화가 시작된다. `대사관 파티 초대장`을 제시하면 연회장 입구로 돌려보내지고 상태는 주의가 된다. 같은 경비에게는 1회만 통하고, 2회째에는 경보로 넘어간다.
- AC-41 "직원 전용 구역"에서는 변장 대화가 통하지 않는다. 구역 경계는 바닥 표지판과 구역 진입 토스트("직원 전용 구역")로 알린다.

### 4.8 자물쇠 따기 (L3 해금)
- AC-42 잠긴 문 앞에서 E를 누르면 자물쇠 미니게임이 열린다. 핀은 3개(금고실 문은 4개)다.
- AC-43 표시기가 막대를 1.2초 주기로 왕복하고, 성공 구간 폭은 막대의 18%다 **(조정값)**. Space로 핀 하나를 맞춘다. 핀이 올라갈 때마다 다음 핀의 성공 구간 위치가 바뀐다.
- AC-44 구간 밖에서 누르면 실패: 반경 6타일 **(조정값)**의 소음 원이 생기고, 그 안의 경비는 `?` 상태로 소음 위치를 조사하러 온다. 진행한 핀은 0으로 돌아간다.
- AC-45 미니게임 중에도 경비는 움직이며, Esc로 언제든 그만둘 수 있다. 3핀 기준 숙련자가 5초 안에 끝낼 수 있어야 한다.

### 4.9 동전 던지기 (L3 해금)
- AC-46 시작 시 동전 0개. 청소부 NPC에게 3개를 받고, 맵에서 2개를 더 주울 수 있다(최대 5개). 남은 개수는 HUD에 표시된다.
- AC-47 G를 누르고 있으면 조준 모드가 된다. 마우스 위치(최대 8타일, 벽 너머는 불가)에 착지 지점과 소음 반경 5타일 원 **(조정값)**을 미리 보여 주고, 반경 안 경비를 노란 테두리로 강조한다.
- AC-48 조준 중 좌클릭으로 던지고 우클릭이나 G를 떼면 취소한다. 착지하면 소리가 나고, 강조됐던 경비가 `?` 상태로 착지 지점으로 가서 4초 둘러본 뒤 원래 경로로 돌아간다.
- AC-49 떨어진 동전은 다시 주울 수 없다.

### 4.10 저장 / 진행
- AC-50 저장 키 `spyGame.save.v1`에 `{version, unlockedLevel, bestGrade{1,2,3}, carriedClues[], settings{volume}}`를 JSON으로 저장한다.
- AC-51 체크포인트에 닿으면 "체크포인트" 토스트와 함께 `spyGame.checkpoint.v1`에 `{level, checkpointId, clues[], items, objectives, coins, usedExcuseGuards[]}`가 저장된다. 경비 위치와 경보 상태는 체크포인트 기본값(평시)으로 되돌린다.
- AC-52 체크포인트 재시작은 입력 후 1초 안에 조작 가능한 상태가 된다. 수첩·아이템·목표 진행은 유지되고, **경보 횟수·경과 시간은 되돌아가지 않는다**(등급 조작 방지).
- AC-53 레벨 선택에서 체크포인트가 남아 있는 레벨은 "이어하기 / 처음부터"를 묻는다. 레벨을 클리어하면 체크포인트를 지운다.
- AC-54 저장 데이터가 깨졌거나 버전이 다르면 기본값으로 초기화하고, "저장 데이터를 초기화했습니다"를 한 번 알린다(크래시 없음).
- AC-55 localStorage 접근이 막힌 환경(프라이빗 모드 등)에서도 게임은 진행되고, 저장이 안 된다는 경고만 띄운다.

### 4.11 결과 / 등급
- AC-56 결과 화면에 소요 시간, 경보 진입 횟수, 단서 수집률(획득/전체), 사용한 동전 수, 등급을 표시한다.
- AC-57 등급 기준 **(조정값)**: S = 경보 0회 + 단서 100% + 목표 시간 이내 / A = 경보 1회 이하 + 단서 80% 이상 / B = 경보 3회 이하 / C = 그 외 클리어. L1은 경보가 없으므로 단서와 시간만 본다.
- AC-58 최고 등급만 저장하고, 이번 기록이 더 좋으면 "최고 기록 갱신"을 표시한다.

### 4.12 레벨별 완료
- AC-59 L1: 정보원 페퍼에게서 `대사관 파티 초대장`을 받으면 잠겨 있던 카페 문이 열린다. 경찰이 순찰하는 부두를 따라 동쪽 끝 출구로 나가면 클리어. 실패 상태가 없다. 경찰은 원뿔만 보이고 감지하지 않으며, 원뿔에 처음 들어가면 "다음 임무부터는 이 원뿔을 피해야 한다" 안내가 한 번 뜬다(L2 예고).
- AC-60 L2: `상회 거래 문서`와 `박사의 메모`를 얻고 주방 뒷문으로 나가면 클리어. 둘 중 하나라도 없으면 뒷문에서 "아직 할 일이 남았다"가 뜨고 나갈 수 없다.
- AC-61 L3: 금고에서 오로라 칩을 꺼내고 화물 엘리베이터(또는 비상 통로)로 탈출하면 클리어. 칩을 꺼내는 순간 무음 경보로 상태가 경보가 되고, 그 직전에 체크포인트가 저장된다.
- AC-62 L1 클리어 시 L2, L2 클리어 시 L3가 해금된다. L3를 클리어하면 엔딩 텍스트 후 크레딧으로 이어진다.

## 7. 조작 (키 바인딩)
| 동작 | 키 | 해금 |
|---|---|---|
| 이동 | WASD / 방향키 | L1 |
| 상호작용·대화·숨기 | E | L1 (숨기 L2) |
| 대화 진행 | Space·Enter / 좌클릭 | L1 |
| 대화 로그 | L | L1 |
| 선택지 고르기 | 1~4 / 좌클릭 | L1 |
| 단서 수첩 | Tab | L1 |
| 웅크리기 | C(토글) / Shift(누르는 동안) | L2 |
| 자물쇠 핀 맞추기 | Space | L3 |
| 동전 조준 / 던지기 / 취소 | G 누르고 있기 / 좌클릭 / 우클릭 또는 G 떼기 | L3 |
| 일시정지·취소 | Esc | 항상 |
- 해금 전 키는 아무 동작도 하지 않는다(안내 토스트 없음). 해금 시 브리핑과 화면 하단 키 안내로 알린다.
