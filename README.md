# 코드네임 모스 (Codename: Moth)

> 단서를 모아 대화로 문을 열고, 그림자로 경비를 피하는 **2D 탑다운 스파이 잠입 웹게임**

신입 요원 **윤하늘(코드네임 모스)** 이 정보기관 '등대'의 임무를 받아 밀수 조직 '까마귀 상회'를 쫓습니다.
조사 단계에서 모은 **단서가 곧 열쇠**입니다. 단서가 있어야 대화 선택지가 열리고, 잠입 경로가 보이고, 금고 번호를 추리할 수 있습니다.

> [!note] 상태
> **v0.1 — 레벨 1~3 플레이 가능.** 단위 테스트 119개, E2E 15개 통과. 수치(감지 시간·경보 타이머 등)는 플레이테스트로 조정 예정입니다.

---

## 특징
- **단서 = 열쇠**: 단서가 없으면 선택지가 회색으로 잠기고 `[단서 필요: …]`가 보입니다. 대화 중 수첩에서 단서를 **제시**해 상대의 반응을 바꿀 수 있습니다.
- **공정한 잠입**: 경비 시야 원뿔(3구역), 감지 게이지, `?`/`!` 아이콘, 경보 띠로 "내가 보이는지" 항상 알 수 있습니다.
- **점진적 능력 해금**: 레벨마다 1~2개씩, 총 6개에서 멈춥니다.
- **전투 없음**: 들키면 숨거나, 말로 넘기거나, 체크포인트에서 다시 합니다.

## 레벨

| 레벨 | 무대 | 새 능력 |
|---|---|---|
| 1 | 항구 카페 '블루 앵커' — 정보원과 접선 | 이동, 대화·단서 제시 |
| 2 | 벨모라 대사관 파티 — 거래 문서 빼내기 | 웅크리기, 숨기 (+ 변장 대화) |
| 3 | 소금곶 지하 연구소 — 오로라 칩 확보 | 자물쇠 따기, 동전 던지기 (+ 단서 연결) |

## 실행 방법

**필요 환경**: Node.js 24 이상, npm 11 이상

```bash
git clone https://github.com/hmkang0513/spy-game.git
cd spy-game
npm install
npm run dev        # http://localhost:5173
```

| 명령 | 설명 |
|---|---|
| `npm run dev` | 개발 서버 |
| `npm run build` | 타입 체크 + 프로덕션 빌드 (`dist/`) |
| `npm run preview` | 빌드 결과 미리보기 |
| `npm run lint` / `npm run typecheck` | 코드 검사 |
| `npm test` | 단위 테스트 (Vitest) |
| `npm run test:e2e` | E2E 테스트 (Playwright, 처음 한 번 `npx playwright install chromium`) |
| `npm run assets` | 캐릭터·타일셋·크레딧 다시 생성 (LPC 원본 캐시 필요, `tools/` 스크립트 상단 참고) |

## 기술 스택

| 분류 | 사용 | 버전 |
|---|---|---|
| 게임 엔진 | Phaser | 4.2.1 |
| 언어 | TypeScript | 6.0.3 |
| 빌드 | Vite | 8.3.2 |
| 테스트 | Vitest / Playwright | 5.0.3 / 1.63.0 |
| 린트·포맷 | ESLint + typescript-eslint / Prettier | 10.12.0 + 8.71.0 / 3.9.9 |
| 폰트 | Galmuri | 2.40.3 |

서버·DB 없음. 진행 상황은 브라우저 `localStorage`에 저장됩니다. 선정 이유는 [기본설계서 §2](docs/02_기본설계서.md)에 있습니다.

## 폴더 구조

```
src/
  core/      순수 게임 로직 (시야·경보·대화·단서·길찾기·저장) — Phaser 없이 테스트
  data/      레벨·대화·단서·캐릭터 데이터
  scenes/    Phaser 씬 (Boot, Title, LevelSelect, Briefing, Level, HUD, Dialogue …)
  entities/  Player, Guard, Npc, Interactable
  ui/ dom/   Phaser UI 컴포넌트 / DOM 단서 수첩
  types/     공유 타입(계약)
public/assets/  스프라이트·타일·폰트 + CREDITS.md
tests/          unit(Vitest) · e2e(Playwright)
docs/           설계 문서
```

## 알려진 이슈
- 감지 시간·경보 타이머·등급 기준 등 조정값은 출처 없는 초안입니다 ([04 §4](docs/04_상세설계서.md)).
- 씬 전환은 일반 페이드입니다(설계상 아이리스 와이프는 미구현).
- 일부 소품(우산·파이프·쟁반 등)과 모자는 LPC에 없어 비슷한 것으로 대체했습니다.
- 붙잡힘 연출 문구, 재시작 1초 이내(AC-52) 등 캔버스 표시는 자동 테스트로 확인하지 않아 수동 확인이 필요합니다.
